## What it is

The strong no-context transformer baseline from the proposal (B3): RoBERTa-base (125M parameters) with a linear
head on the `<s>` token, fine-tuned on **one utterance at a time**, with no dialogue context and no speaker. B4
(context-aware RoBERTa) can start from its weights and ShiftAware (#6) runs on its cached utterance embeddings.

- Code: `emotionshift/models/roberta.py` (`RobertaUtterance`: fit, predict, predict_proba, attributions, embed, save/load)
- Config: `configs/b3_roberta.yaml` — lr 1e-5, batch 32, 10% warm-up, fp16, max 128 tokens; MELD 4 epochs,
  DailyDialog 3 epochs; plain cross-entropy (class weights are B4+)
- Chosen on **dev only**: after every epoch the model is scored on dev (MELD weighted-F1, DailyDialog micro-F1
  excl. neutral) and the best epoch is kept; 5 seeds; the best-on-dev seed is saved for the demo
  (MELD seed 1, DailyDialog seed 0)
- Dev scores per seed: MELD 58.7 / 59.1 / 58.1 / 58.4 / 58.9; DailyDialog 60.6 / 59.2 / 58.0 / 59.8 / 58.5

### MELD test by emotion shift (gold shift labels, mean over seeds)

| Group | n | Weighted-F1 | Macro-F1 | B1 weighted-F1 |
|---|---|---|---|---|
| all | 2610 | 62.8 | 40.6 | 56.8 |
| stratum:first | 746 | 65.2 | 40.1 | 62.2 |
| stratum:stable | 861 | 69.7 | 38.7 | 62.1 |
| stratum:shift | 1003 | 55.9 | 40.5 | 49.1 |
| shift_type:onset | 355 | 50.2 | 30.5 | 46.3 |
| shift_type:offset | 340 | 91.8 | 13.1 | 85.9 |
| shift_type:surprise | 158 | 60.8 | 33.5 | 51.6 |
| shift_type:within_negative | 81 | 31.8 | 11.3 | 32.1 |
| shift_type:valence_flip | 69 | 57.8 | 28.2 | 45.4 |

- **The shift gap survives without context**: 69.7 on stable turns vs 55.9 on shift turns (B1: 62.1 vs 49.1).
  B3 never sees the previous turn, so it cannot copy the previous emotion: turning points are harder to read
  from the utterance itself. Context models should be judged on how much of this gap they close.
- B3 gains on every shift type except **within-negative** (anger → sadness etc.), which stays at ~32 for both models.
- **Rare classes**: with plain cross-entropy B3 almost never predicts disgust or fear (0–6 such predictions per
  seed for 118 gold cases on MELD test; per-class F1 0 on seed 0). Class weights / focal loss are the B4+ fallback.
- Longer utterances are harder: 69.8 weighted-F1 for 1–3 words, 53.0 for 16+ words.
- **Transfer (E8)**: the MELD model on DailyDialog scores 40.9 micro-F1 (55.3 in-domain) and predicts a shift on
  27% of eligible turns against a true rate of 18% (in-domain model: 24%), as hypothesis H6 expects.

## Using the model (demo, B4, ShiftAware)

The trained models are ~500 MB each, so they are **not in Git**. They are in the shared Google Drive folder
`EE6405_EmotionShift/b3_out/models/` (`b3_meld`, `b3_dailydialog`); ask KL Y for access. Each folder also holds
`embeddings_<split>.npy` (float16, one 768-d `<s>` vector per utterance) and `embeddings_index.csv` (row order)
for ShiftAware.

```python
from emotionshift.models.roberta import RobertaUtterance
m = RobertaUtterance.load("models/b3_meld")       # the downloaded folder
m.predict(["Oh my God!", "Yeah."])                # -> list of emotions
m.predict_proba(["Oh my God!"])                   # (n, 7), label order neutral, joy, surprise, anger, sadness, disgust, fear
m.attributions("Wow, that's amazing!")            # (words, IG scores, predicted emotion, probability)
m.embed(texts)                                    # (n, 768) <s> vectors
```
