## What it is

The traditional-ML baseline from the proposal (B1): each utterance becomes a
TF-IDF vector over word 1–2-grams (with `!` and `?` kept as tokens), and a
linear SVM (one-vs-rest, balanced class weights) predicts one of the 7 emotions.
It reads **one utterance at a time**, with no dialogue context and no speaker,
so it is the reference point the context-aware models (#4–#6) must beat.

- Code: `emotionshift/models/tfidf.py`
- Config and dev grid: `configs/b1_tfidf.yaml` (classifier × C × class weight × features, 32 settings on MELD)
- Chosen on **dev only**: MELD linear SVM C = 0.1, balanced, word n-grams; DailyDialog linear SVM C = 0.3, balanced, word n-grams

Short, lexically marked emotion is captured; tone, sarcasm and context are not
(a one-word "Yeah." is always neutral).

## Using the model (demo interface)

```python
from emotionshift.models.tfidf import TfidfBaseline
m = TfidfBaseline.load("models/b1_meld.joblib")   # created by scripts/train_b1.py
m.predict(["Oh my God!", "Yeah."])                # -> list of emotions
m.predict_proba(["Oh my God!"])                   # (n, 7), label order neutral, joy, surprise, anger, sadness, disgust, fear
m.top_features(10)
```
